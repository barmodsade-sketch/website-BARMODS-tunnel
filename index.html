Panduan Klien & Konfigurasi Operator

Petunjuk impor kredensial pada perangkat pengguna serta format variabel environment untuk deployment 1-klik di Vercel.

Panduan Penggunaan Aplikasi Klien

Aplikasi Klien yang Kompatibel (Android, iOS, Desktop, OpenWrt)
  • Android: HTTP Custom (untuk format SSH + Payload WS / UDP), v2rayNG, NekoBox, dan Sing-box.
  • iOS & macOS: Shadowrocket, Streisand, FoXray, atau Sing-box melalui tautan URI vmess://, vless://, dan trojan://.
  • Windows & Linux: v2rayN, Nekoray / Throne, atau klien OpenSSH terminal.
  • Router OpenWrt: PassWall2, OpenClash, dan Nikki dengan menyalin parameter UUID, domain, port 443/80, serta path WebSocket/gRPC.
Cara Mengimpor Tautan TLS, HTTP WS, dan gRPC

Gunakan URL TLS (Port 443) untuk jaringan standar dengan enkripsi penuh SNI, atau pilih URL HTTP (Port 80) apabila skema injeksi bug host Anda mengandalkan jabat tangan HTTP non-TLS.

Klik tombol Salin pada salah satu tautan di Lembar Kredensial, buka aplikasi v2rayNG atau NekoBox, lalu pilih menu Import config from Clipboard.

Kebijakan Batas IP dan Rate-Limit Trial Publik

Setiap alamat IP pengunjung dibatasi maksimal 5 pembuatan akun Trial per 15 menit (dapat disesuaikan oleh operator melalui TRIAL_RATE_LIMIT_MAX) guna menjaga kestabilan node dari penyalahgunaan otomatis.

Pastikan jumlah perangkat yang terhubung bersamaan tidak melewati nilai Batas Login (IP) agar sesi tidak diputus otomatis oleh daemon node.

Konfigurasi Environment Vercel

SERVERLESS ENV

Tambahkan variabel berikut pada menu Project Settings > Environment Variables di Vercel. Token auth disimpan aman di sisi server dan tidak pernah dikirim ke browser pengunjung. 

VPN_SERVERS_JSON=[{"id":"sg-01","name":"Singapore Node 01","region":"Singapore","isp":"Example Cloud","domain":"sg1.example.com","port":5888,"auth":"GANTI_TOKEN_AUTH_NODE"}]
ADMIN_PIN=GANTI_PIN_OPERATOR
TRIAL_RATE_LIMIT_MAX=5

Doctor Barmods Clinical Clean Ops Console menyediakan antarmuka pembuatan kredensial tunnel langsung ke node port-5888 milik operator tanpa menyimpan riwayat password atau token otorisasi di sisi klien.
